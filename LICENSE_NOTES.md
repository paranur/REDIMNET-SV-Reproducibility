# Provenance and license notes

This is the authors' score-level reproducibility release for the associated manuscript. The release contains derived scores, author-created evaluation code, non-audio protocol identifiers, and numerical evidence. Publication of this package does not grant a new license to underlying speech, videos, model weights, or third-party code. The existing repository did not specify a repository-wide software/data license; this update does not invent one. For reuse beyond inspection and reproduction, obtain appropriate permission from the repository owner and the relevant rights holder.

VoxCeleb references identify speakers and recordings by official dataset IDs and relative recording paths; they contain no recordings or added real-name mapping. Obtain audio under the original access and use conditions; cite Nagrani et al. (2017), Chung et al. (2018), and Nagrani et al. (2019), as appropriate. Official dataset and privacy notice: https://www.robots.ox.ac.uk/~vgg/data/voxceleb/ . This release does not infer unrestricted audio redistribution rights from availability of protocol metadata.

USC protocol identifiers and derived scores were already present publicly at the baseline commit; this release adds no private USC dataset. Cite Musaev et al., USC: An Open-Source Uzbek Speech Corpus and Initial Speech Recognition Experiments (SPECOM 2021). The maintainer's dataset card currently labels the hosted dataset MIT: https://huggingface.co/datasets/issai/Uzbek_Speech_Corpus/blob/main/README.md . Check the distribution you obtain and its accompanying terms rather than assuming one label covers all mirrors or source recordings.

ReDimNet implementation: https://github.com/IDRnD/ReDimNet . Its upstream LICENSE identifies MIT, copyright 2024 ID R&D, Inc.: https://github.com/IDRnD/ReDimNet/blob/master/LICENSE . No model implementation or checkpoint binaries are copied here. Checkpoint names and exact hashes of the local files used are recorded in provenance/checkpoint_identifiers.csv; FT-LM files are state_dict exports, so byte hashes need not equal an upstream container's hash. Upstream checkpoints and datasets must be acquired independently for inference-level work. No claim is made that an upstream latest release is immutable or byte-identical.

Python numerical dependencies retain their own licenses and are not vendored. No credentials, audio, embeddings, checkpoint binaries, original private datasets or private machine roots are included in the current release tree. Historical commits remain intact and may contain old machine-root metadata; the new tree normalizes those metadata fields without changing numerical scores, labels, trial identity suffixes or frozen values. Original and released hashes and the normalization scope are documented in provenance/. This is a content and provenance review, not a guarantee of legal rights outside the stated release scope.
