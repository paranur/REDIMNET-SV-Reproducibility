# MR-03 release additions and exclusions

Baseline: `adc1f366453bf4ef737c374c0a3a614e9300d59e`. All changes are a forward commit on the existing main branch; no history rewrite.

Added: portable MR-01/MR-02 implementations and configurations; exact expected numerical tables; canonical speaker/recording endpoints; FT-LM and cleaned frozen scores/audits; official protocols; existing USC/FT-LM numerical references; six checkpoint identifiers/hashes; package-only runner, integrity verifier and privacy scanner; tested requirements and executable documentation.

Existing metadata changes: machine roots normalized to portable identifiers only; scientific values, frozen decisions and pairings preserved. The initial Git blobs used normalized line endings while original source/checksum bytes used CRLF. This release preserves scientific-source bytes and disables Git newline conversion through .gitattributes. Every baseline file is compatibility-checked in provenance/baseline_compatibility.csv. Existing README and checksums replaced after baseline identity/compatibility checks. Full before/after hashes are in provenance/.

Excluded: audio, checkpoints, embeddings, private datasets, credentials, private local machine roots, manuscript, reviewer responses and local experiment journal. Historical commits remain available. No new scientific experiment, trial generation, inference, training, threshold fitting or policy selection.

License note: no blanket repository license is invented; underlying resources retain their own terms. See LICENSE_NOTES.md.
